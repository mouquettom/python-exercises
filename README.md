# Python Exercises

A collection of 12 short Python exercises covering the fundamentals: user input, data structures, comprehensions, functions, decorators and object-oriented programming.

Code comments and console output are written in French.

## Requirements

- Python 3 (no third-party dependencies)

## Usage

Run any exercise from the repository root:

```bash
python exo_01.py
```

Exercises 01, 02, 05 and 07 are interactive and ask for input in the terminal.

## Exercises

| File | Topic | Description |
|------|-------|-------------|
| `exo_01.py` | Input & f-strings | Asks for a name and an age, then prints a greeting. |
| `exo_02.py` | Nested dictionaries | Looks up a student's grades by name, asking again until a known student is entered. |
| `exo_03.py` | List comprehensions | Counts the vowels in each word of a list and returns `(word, count)` tuples. |
| `exo_04.py` | Classes | Two simple classes that store a name and display it (definitions only, no output when run). |
| `exo_05.py` | Functions | Reads two integers and prints their sum and difference. |
| `exo_06.py` | Functions | Computes the average of a list of numbers. |
| `exo_07.py` | Input validation | Prompts until a valid number is entered, then prints its square. |
| `exo_08.py` | Decorators | A logging decorator that prints a message before and after a function call. |
| `exo_09.py` | Classes | A `Rectangle` class with area and perimeter methods. |
| `exo_10.py` | Inheritance | A `Person` base class and an `Employee` subclass that extends `display_details()` with `super()`. |
| `exo_11.py` | Encapsulation | A `BankAccount` class with deposits, withdrawals and balance checks. |
| `exo_12.py` | Composition | A `Library` managing `Book` objects: add, remove, borrow, return and list books. |
